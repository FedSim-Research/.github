# Organization profile

[profile/README.md](profile/README.md) is the landing page for **FedSim Research**.
Project details and setup instructions belong in the main FedSim repository.
Profile images are self-contained under `profile/assets/`. The dark-mode editor
screenshot shows an illustrative two-edge hierarchy, not a submitted experiment.
The result plot is unchanged output of the main repository's
[feedback analysis](https://github.com/FedSim-Research/fedsim/blob/main/experiments/analysis/generate_lr_ablation.py).

GitHub displays `profile/README.md` on the organization overview once it is pushed to the
default branch of a **public** `.github` repository. See the
[GitHub profile documentation](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/customizing-your-organizations-profile).
